Dossiê de defesa de chargeback

Um agente consulta as provas de uma compra contestada por meio de um servidor MCP, monta o dossiê e espera a aprovação do produtor antes de qualquer envio.

Simulação com dados fictícios. O agente desta página segue um roteiro fixo e não usa um modelo de linguagem. O servidor MCP real, com as mesmas ferramentas, está no repositório do projeto. Nenhum dado aqui vem da YouShop.

MCP consulta somente leitura ao servidor. Regra verificação comum, sem IA.

    3. Dossiê para revisão

    4. Decisão do produtor

    O agente nunca envia nada sozinho. Esta etapa é humana.

    Quem faz o quê

    Regra

    Onde há certeza

    Calcular o prazo de 2 dias e conferir se um comprovante de entrega seria aceito. Código comum resolve, sem IA.

    MCP

    Onde há integração

    Expor pedido, logs de acesso, rastreio e conversas ao agente por uma interface única, somente leitura.

    IA na versão real

    Onde há interpretação

    Um modelo de linguagem escolheria as provas certas para cada motivo de contestação e redigiria a defesa. Nesta simulação, esse passo usa um texto fixo.

    O prazo de 2 dias corridos e a lista de provas seguem os Termos de Uso públicos da YouShop (versão de outubro de 2025). Os pedidos, nomes e valores são inventados para a demonstração.
